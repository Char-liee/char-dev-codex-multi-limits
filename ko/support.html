지원 및 설정 안내

로그 기반 토큰 통계를 모으려면 Mac 앱이 필요합니다. 현재 앱 화면은 한국어로 제공됩니다.

Char Dev 문의: jonghojo1998@gmail.com. 공개 배포는 아직 준비 중입니다.

기기 연결하기

  1. Mac에서는 macOS 14 이상, iPhone에서는 iOS 17 이상을 사용하세요. iPad에 최적화된 화면은 제공하지 않습니다.
  2. 계정별 잔여 한도를 보려면 설정 → 계정 관리에서 계정을 추가하세요. 인증은 시스템 브라우저의 OpenAI 페이지에서 진행합니다.
  3. Mac에서 설정 → 토큰 통계 설정을 열고, sessions와 archived_sessions가 들어 있는 .codex 폴더를 선택하세요.
  4. iPhone에서 토큰 통계를 보거나 여러 Mac의 기록을 합치려면 각 기기에서 같은 Apple 계정을 사용하고 iCloud 토큰 통계 동기화를 켜세요.
  5. 전체 동기화로 새로고침하세요. 계정과 설정의 동기화, 토큰 통계 동기화는 별도의 기능입니다.

자주 묻는 질문

iPhone의 토큰 통계가 비어 있어요.

iPhone은 Mac의 Codex 파일을 직접 읽지 못합니다. Mac에서 로그 폴더를 연결하고 두 기기의 토큰 통계 동기화를 켠 뒤, Mac 앱이 실행 중일 때 새로고침하세요.

위젯에 이전 값이 표시돼요.

앱은 위젯 갱신을 요청하지만 실제 반영 시각은 Apple 시스템이 결정합니다. 앱을 새로고침하고 계정 조회 시각 또는 마지막 토큰 집계 시각을 확인하세요. 잠자기 상태의 Mac은 새 로컬 기록을 업로드하지 못합니다.

API 환산액이 실제 청구액인가요?

아닙니다. 기록된 토큰과 모델별 표준 단가로 계산한 추정 금액입니다. 구독료, 세금, 도구 비용, 긴 문맥 추가요금, 속도나 서비스 등급에 따른 추가요금은 제외합니다. 단가를 알 수 없는 모델의 토큰은 합계에 포함하지만, 단가를 지정할 때까지 금액에서는 제외합니다.

일부 날짜에 기록이 없어요.

남아 있는 Codex 로그만 집계합니다. 웹에서만 사용한 기록, 삭제된 원본 로그, 아직 동기화하지 않은 다른 Mac의 기록은 빠질 수 있습니다. 빈 날짜는 집계된 기록이 없다는 뜻이며, 그날 Codex를 사용하지 않았다는 뜻은 아닙니다.

활동 계정을 선택하면 토큰 합계도 바뀌나요?

아닙니다. 토큰 합계와 일별 그래프는 모든 Mac과 계정을 합산합니다. 활동 화면의 계정 선택은 주간 한도 활동 히트맵에만 적용됩니다.

동기화를 끄거나 계정을 삭제하면 어떻게 되나요?

동기화를 끄면 동기화가 중단되지만 기존 캐시나 클라우드 기록은 삭제되지 않습니다. 계정을 삭제해도 전체 토큰 통계나 OpenAI 계정은 지워지지 않습니다. 보관 및 삭제 범위를 확인해 주세요.
