Mac에서 집계하고,
iPhone에서 확인하세요.

토큰 통계는 Mac의 Codex 세션 로그에서 집계합니다. iCloud 토큰 동기화를 켜면 iPhone에서도 이 통계를 받을 수 있습니다.

  • Codex 로그 폴더 연결Mac 앱이 로컬 파일의 토큰 수와 메타데이터를 읽습니다. 원본 세션 파일은 그대로 둡니다.
  • 토큰 통계 동기화 켜기각 기기에서 같은 Apple 계정을 사용하세요. 복사된 동일 세션 기록은 중복 집계하지 않습니다.
  • 최근 사용량 확인일별 토큰은 모든 Mac과 계정의 합계입니다. 활동 히트맵은 주간 잔여 한도가 줄어든 시각을 바탕으로 따로 추정합니다.

환산액의 기준을 확인하세요.

API 환산액은 기록된 토큰 수와 모델별 단가로 계산합니다. 구독료나 실제 API 청구액이 아닙니다. 단가를 알 수 없는 모델은 단가를 지정할 때까지 금액에서 제외합니다.

달러와 원화를 지원합니다. 원화는 선택한 환율을 기간 전체에 적용합니다. 누락된 로그, 웹에서만 사용한 기록, 아직 동기화하지 않은 Mac의 기록은 빠질 수 있습니다.
