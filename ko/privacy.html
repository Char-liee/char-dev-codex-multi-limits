앱이 데이터를 사용하는 방식

Codex Multi Limits에는 개발자가 운영하는 백엔드나 광고 및 분석 SDK가 없습니다. 다만 OpenAI 직접 요청, 선택적 Apple CloudKit 동기화, 공개 환율 및 서비스 상태 조회 과정에서는 일부 정보가 기기 밖으로 전송됩니다.

데이터사용 목적과 저장 및 전송 위치
로그인 인증정보OAuth 액세스 토큰, 갱신 토큰, ID 토큰은 이 기기의 공유 키체인에 저장합니다. OpenAI에 직접 인증 요청을 보낼 때 사용하며, 앱은 이를 CloudKit에 업로드하지 않습니다.
계정 정보이메일, 별명, 고유한 사용자 또는 워크스페이스 식별자, 플랜, 한도 조회 결과, 설정을 로컬에 저장합니다. 계정 동기화를 켜면 Apple 계정의 비공개 CloudKit 데이터베이스에도 저장합니다.
토큰 통계해시 처리한 이벤트 ID, 시각, 모델, 토큰 수, 원래 세션 ID, Mac 기기 표시 이름을 로컬에 저장합니다. 토큰 통계 동기화를 켜면 비공개 CloudKit 데이터베이스에 업로드합니다.
환율과 서비스 상태Frankfurter에서 달러와 원화의 환율을 조회하고, OpenAI의 공개 상태 서비스에서 서비스 상태를 확인합니다. 이 요청에는 계정 인증정보나 사용량 통계를 포함하지 않습니다.

로그인과 기기 내 저장

계정 인증은 시스템 브라우저의 OpenAI 페이지에서 진행합니다. 앱은 인증 후 받은 정보를 사용해 OpenAI에 직접 사용량 조회와 인증 갱신을 요청합니다. 앱 자체의 비밀번호 로그인 화면은 제공하지 않습니다.

인증정보는 각 기기의 시스템 키체인에 저장하며 앱은 이를 CloudKit으로 동기화하지 않습니다. 계정 기록, 사용량 캐시, 표시 설정, 토큰 요약은 같은 기기의 앱 위젯과 공유될 수 있습니다. 앱을 삭제한다고 해서 공유 키체인, 클라우드, 백업의 모든 데이터가 삭제된다고 보장하지 않습니다.

Mac의 Codex 로그

Mac 앱은 로컬 세션 로그 파일을 읽어 토큰 수와 메타데이터를 추출합니다. 저장하거나 동기화하는 토큰 통계에는 프롬프트, 생성된 코드, 프로젝트 경로를 포함하지 않습니다. 앱은 원본 로그 파일을 수정하거나 삭제하지 않습니다.

토큰 통계는 각 기록을 어느 Codex 계정에서 사용했는지 분류하지 않고 모든 계정과 Mac을 합산합니다. 세션 식별자와 기기 이름은 익명 정보가 아닙니다.

선택적 iCloud 동기화

두 동기화 기능은 기본적으로 꺼져 있습니다. 켜면 Apple 계정의 비공개 CloudKit 저장소를 사용합니다. 각각 별도로 설정할 수 있습니다.

  • 계정과 설정 동기화에는 계정 이메일, 별명, 사용자 또는 워크스페이스 ID, 플랜, 한도 조회 결과, 최근 사용량 기록과 히트맵, 알림 설정, 통화와 환율 및 집계 기간 설정, 모델 단가 지정 내용이 포함됩니다.
  • 토큰 통계 동기화에는 세션 ID와 Mac 표시 이름을 포함한 토큰 기록의 메타데이터와 토큰 수가 포함됩니다. OAuth 인증정보, 프롬프트, 생성된 코드, 프로젝트 경로는 포함하지 않습니다.

이 초안에서는 해당 기록이 종단간 암호화된다고 주장하지 않습니다. CloudKit은 Apple이 운영하며, 인증 및 사용량 서비스는 OpenAI가 운영합니다.

보관 기간과 삭제 범위

앱의 토큰 통계 집계 범위는 오늘을 포함한 최근 30일입니다. 사용량 기록과 히트맵도 오래된 기록을 정리합니다. 정리 작업은 앱이 실행될 때 이루어지며, 만료된 클라우드 토큰 기록은 동기화가 켜져 있고 정상적으로 완료될 때만 삭제합니다. 모든 사본이 30일 후 삭제된다고 일괄적으로 보장하지 않습니다.

  • 동기화 기능을 끄면 동기화가 중단됩니다. 기존 로컬 캐시와 클라우드 기록은 남습니다.
  • 계정을 삭제하면 삭제를 실행한 기기에서 앱의 로그인 토큰과 로컬 사용량 기록을 지웁니다. 계정 동기화가 켜져 있으면 계정 삭제도 동기화합니다. 1.6 (20)으로 업데이트한 다른 기기도 삭제를 수신한 뒤 앱 로그인 토큰을 제거합니다. 이 동작은 OpenAI 계정을 삭제하거나 OpenAI의 인증 토큰을 무효화하지 않습니다.
  • 현재 삭제 표식에는 계정 정보를 포함한 전체 계정 객체가 남으며, 정해진 만료 시점이 없습니다. 이 표식은 오래된 기기가 삭제된 계정을 다시 복원하지 못하게 합니다.
  • 삭제를 아직 수신하지 않은 기기의 토큰, 전체 토큰 합계, 일부 로컬 히트맵 기록, 백업, 기존 클라우드 데이터가 계정 삭제만으로 모두 지워지는 것은 아닙니다.
  • 현재 앱에는 클라우드 데이터를 완전히 삭제하는 화면이 없습니다. 최종 보관 기간과 공개 삭제 요청 절차는 출시 전에 확정해야 합니다.
