Privacy information

This draft describes the current app implementation, reviewed on October 6, 2026. It is not a finalized public-release privacy policy.

Operator: Char Dev. Privacy questions: jonghojo1998@gmail.com. The final retention policy and any release changes must be confirmed before launch.

How the app uses data

Codex Multi Limits has no developer-run backend or bundled advertising/analytics SDK. Some data still leaves your device through direct requests to OpenAI, optional Apple CloudKit synchronization, and public exchange-rate/status services.

DataPurpose and destination
Sign-in credentialsOAuth access, refresh, and ID tokens are stored in this device's shared Keychain. They are used for direct authenticated requests to OpenAI and are not uploaded by the app to CloudKit.
Account informationEmail, nickname, stable user/workspace identifiers, plan, quota snapshots, and settings are stored locally. Optional account sync copies these to your Apple-account private CloudKit database.
Token statisticsHash event IDs, timestamps, models, token counts, raw session IDs, and Mac device display names are stored locally. Optional token-statistics sync uploads them to your private CloudKit database.
Exchange rates and statusRequests to Frankfurter obtain the USD/KRW rate. Requests to OpenAI's public status service obtain service status. The app does not include account credentials or usage statistics in these requests.

Sign-in and device storage

Account authentication opens OpenAI in the system browser. The app uses the resulting credentials to query account usage and refresh authentication directly with OpenAI. It does not provide its own password-login form.

Credentials use device-only Keychain storage. Account records, cached usage, display settings, and token summaries may be shared locally with the app's widgets. Removing the app should not be treated as a guarantee that all shared Keychain, cloud, or backup data has been erased.

Codex logs on your Mac

The Mac app reads session log files locally to extract token counters and metadata. Its stored and synchronized token statistics do not include prompts, generated code, or project paths. The original log files are not modified or deleted by the app.

Token statistics combine all accounts and Macs rather than identifying the Codex account used for each event. Session identifiers and device names are not anonymous data.

Optional iCloud synchronization

Both sync options are off by default. When enabled, they use private CloudKit storage associated with your Apple account. They are separate options:

  • Account and settings sync includes account email, nickname, user/workspace IDs, plan, quota snapshots, recent usage history and heatmap, notification preferences, currency/rate/period settings, and model-price assignments.
  • Token-statistics sync includes token-event metadata and counts, including session IDs and Mac display names. OAuth credentials, prompts, generated code, and project paths are not included.

This draft makes no claim that these records use end-to-end encryption. Apple operates CloudKit, and OpenAI operates the authentication and usage services.

Retention and deletion limits

The active token-statistics window is the most recent 30 calendar days. Usage history and heatmap records also have recent-history pruning. Cleanup depends on the app running, and expired token cloud records are removed only during successful enabled synchronization. There is no universal guarantee that every copy is erased after 30 days.

  • Turning either sync option off stops synchronization. Existing local caches and cloud records remain.
  • Removing an account deletes its app login token and local usage history on the device where you remove it. Account removal is synchronized when account sync is enabled. This does not delete your OpenAI account or revoke the token at OpenAI.
  • Deletion records currently retain the full account object, including account information, without a scheduled expiry. These records prevent older devices from restoring a removed account.
  • Tokens stored on other devices, global token totals, some local heatmap records, backups, and existing cloud data are not all removed by deleting an account.
  • The current app does not offer a complete cloud-data purge interface. Final retention periods and a public deletion-request process must be confirmed before launch.

Diagnostics and website

App diagnostics are off by default. A developer can enable local file/OS logs and Apple's MetricKit through a process environment setting. Diagnostic files are shared only through an explicit manual share action in the app.

This website contains no analytics, advertising, forms, or tracking scripts. It is hosted on GitHub Pages. GitHub logs and stores visitors' IP addresses for security purposes, whether or not visitors sign in to GitHub.
